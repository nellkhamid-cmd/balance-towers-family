# «Баланс Тауэрс»: лендинг «Семейные квартиры бизнес-класса»

Статичная страница без сборки и без библиотек. Заменяет Тильда-страницу https://3.sm-balancetowers.ru/family.
Сейчас опубликована на GitHub Pages: https://nellkhamid-cmd.github.io/balance-towers-family/

## Состав

| Путь | Что это |
|---|---|
| `index.html` | Страница целиком, код Метрики в `<head>` |
| `css/main.css` | Стили |
| `js/main.js` | Анимации, квиз в окне, форма «Получить каталог», цели Метрики |
| `img/` | Картинки, логотип, фавиконы (`favicon.svg`, `apple-touch-icon.png`) |
| `favicon.ico` | Фавикон для старых браузеров, должен лежать в корне сайта |
| `fonts/` | Muller: Light, Regular, Medium |
| `video/` | Ролик: `balance-1080.mp4` для компьютеров (15 МБ), `balance-720.mp4` для телефонов (7 МБ) |
| `.nojekyll` | Нужен только для GitHub Pages, на другом хостинге не нужен |

На хостинг выкладывать всё, кроме `README.md`. Локально открыть: `python -m http.server` из этой папки, затем http://localhost:8000.

## Перед запуском

1. **Номер счётчика Метрики.** В `index.html` вписать номер в двух местах:
   - `window.YM_ID = 0;` в `<head>` — вместо `0`;
   - `<noscript>` в начале `<body>` — вместо `НОМЕР_СЧЁТЧИКА`.

   Пока `YM_ID = 0`, Метрика не загружается. Код счётчика стандартный, с Вебвизором, картой кликов и точным показателем отказов.
2. **Цели в Метрике** — создать по таблице ниже.
3. **Счётчик в Marquiz.** Цели квиза отправляет сам Marquiz в счётчик из настроек квиза. Сейчас там указан **111595291** (счётчик страницы /family). Если на лендинге будет другой счётчик, его номер нужно добавить в Marquiz: квиз `6aed6ebedb3d61000ff6911d` → «Интеграции» → «Яндекс Метрика».
4. **Куда уходят заявки формы.** В `js/main.js` в `CONFIG.FORM_ENDPOINT` указать обработчик (CRM или вебхук). Форма отправляет JSON методом POST: `name`, `phone`, `consent`, `ads_consent`, `utm_*`, `request`, `offer`, `page`, `submitted_at`. **Пока поле пустое, заявка никуда не уходит**, хотя посетитель видит «Заявка принята».
5. **Ссылки на согласия и политику** ведут на 3.sm-balancetowers.ru. Если домен будет другой, проверить их.
6. **Шрифт Muller** коммерческий: проверить лицензию на веб.

Индексация открыта: `noindex` убран.

## Цели Яндекс Метрики

Все цели — тип «JavaScript-событие», идентификатор вписать точно как в таблице.

### Квиз Marquiz (отправляет Marquiz)

| Цель | Идентификатор |
|---|---|
| Открытие квиза окном (кнопки «Подобрать квартиру») | `quiz_open` — отправляет страница |
| Квиз загрузился (и в окне, и встроенный в блок «Подбор») | `marquiz-start` |
| Прошёл 1-й вопрос | `marquiz-step1` |
| Прошёл 2-й вопрос | `marquiz-step2` |
| Дошёл до формы контактов | `marquiz-form` |
| Отправил квиз (оставил контакты) | `marquiz-finish` |

Квиз работает во фрейме Marquiz с другого домена, поэтому страница не видит, что происходит внутри. Эти цели Marquiz отправляет сам и только в счётчик из своих настроек (п. 3 выше).

Отдельной цели «заполнил поля контактов, но не отправил» в квизе нет. Ближайшие: `marquiz-form` (увидел форму контактов) и `marquiz-finish` (отправил).

`marquiz-start` срабатывает при каждой загрузке встроенного квиза, то есть почти у всех, кто долистал до блока «Подбор». Поэтому как «открытие квиза» лучше считать `quiz_open`.

### Форма «Получить каталог» (отправляет страница)

| Цель | Идентификатор | Когда срабатывает |
|---|---|---|
| Заполнил форму | `form_fill` | Имя (от 2 букв) и телефон (10 цифр после +7) введены верно. Один раз за визит |
| Отправил форму | `form_submit` | Форма прошла проверку и успешно отправлена |

Цели страницы (`quiz_open`, `form_fill`, `form_submit`) также уходят в `dataLayer` как `{event: "<идентификатор>"}` — для Google Tag Manager, если он появится.

## Блоки страницы

| Порядок | Блок | Что на нём |
|---|---|---|
| 1 | Первый экран | Заголовок и цена, «Подобрать квартиру» (квиз в окне), «Получить каталог семейных квартир» (форма в окне), бейджи премий, «Скоро сдача» |
| 2 | Цифры | 22 и 37 этажей · 130 м смотровая · 3 уровня паркинга · 70% квартир с видом на Волгу |
| 3 | Для семьи `#why` | 4 фото-карточки: безопасность, тишина и уют, всё рядом, время для семьи. На телефоне листаются свайпом |
| 4 | Квиз `#quiz` | Квиз Marquiz https://mrqz.me/6aed6ebedb3d61000ff6911d встроен в страницу |
| 5 | Трейд-ин `#move` | «Бесплатный трейд-ин вашей квартиры», как это работает, кнопки «Получить каталог» и «Подобрать квартиру» |
| 6 | Видео `#film` | Во всю ширину, стартует само без звука, когда блок на экране. Плашка «Больше никаких компромиссов» и «Получить каталог» |

**Заявки.** Все кнопки «Подобрать квартиру» открывают квиз в окне Marquiz. Все кнопки «Получить каталог» открывают одну форму: имя, телефон, два согласия. UTM-метки из адреса страницы подставляются в заявку формы.

**Если Marquiz не загрузился** за 6 секунд (блокировщик рекламы, сеть) или страница открыта из папки двойным щелчком, встроенный квиз вставляется напрямую с `https://quiz.marquiz.ru`, а кнопки «Подобрать квартиру» открывают квиз в новой вкладке.
